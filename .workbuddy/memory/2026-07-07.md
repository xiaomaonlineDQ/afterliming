## 地图页探索机制完善（2026-07-07 19:13）

### 背景
小马指出地图页目前只能模拟闹鬼（第0天变鬼），地图探索机制（Day 1+的回合内探索流程）缺失。

### 新增功能

**1. 第1天黎明地图设置面板**
- 按钮「生成第1天黎明地图设置」→ 市长对12个地点执行三判定：
  - 物资数量：1-12随机数（每地点独立）
  - 事件判定：抛硬币（人面=含事件）
  - 鬼判定：仅限含事件地点，再抛硬币（鬼面=有鬼）
- 结果以网格形式展示（东区6 + 西区6），含统计行（总物资/含事件地点数/有鬼地点数）
- 每个地点卡片同步显示状态徽章（📦数量 / ⚡事件 / 👻有鬼）
- 支持重新生成

**2. 地图探索模拟器**
- 玩家身份选择：回合玩家（主角光环） vs 非回合玩家（高风险）
- 地点选择：下拉框 + 点击地图标记/卡片联动选择
- 点击「开始探索」→ 逐步展开完整探索流程（5步）：
  - 步骤0：公开宣言 · 选择地图探索
  - 步骤1：健康 -1（放置指示物）
  - 步骤2a：物资获取（从牌库抽N张，N=该地点设置物资数）
  - 步骤2b：事件判定（掷硬币→抽1张反击卡 / 无事发生）
  - 步骤2c：鬼判定（无事件地点跳过 / 有事件无鬼→安全 / 有鬼→撞鬼处理）
- 撞鬼处理差异化展示：
  - 回合玩家：理智-1 + 特殊规则激活 + 不被同化（三种后果逐条展示）
  - 非回合玩家：被同化为恶鬼 + 恶鬼面板（理智5/5 + 抽存活人类数规则）+ 恶鬼代价警告
- 撞鬼地点绑定的特殊规则在结果中展示

**3. UI联动优化**
- 点击地图标记/地点卡片 → 自动选中探索模拟器的下拉框 + 高亮 + 滚动到对应面板区域
- 探索完成后的地点卡片不做视觉变化（同一地点可被多回合多次探索）

### 技术细节
- 全局状态 `mapSetup`：存储12个地点的三判定结果
- 探索结果以 `explore-step` 组件逐条渲染，撞鬼步骤高亮红色边框
- 回合/非回合撞鬼差异完全对照地图系统子稿V1.9.1

## 🖼️ 卡牌图片路径修复 + 全验证通过（2026-07-07 22:47）

### 背景

### 问题诊断（三重错误）

**错误1：缺少子目录层级**
旧路径 `images/cards/反击卡_基础_偷窃.png` → 缺少 `反击卡/` 子目录。
文件名中嵌入了类型名，但目录结构是 `images/cards/{类型}/`。

**错误2：反击卡前缀错误**
源文件实际命名是 `事件卡_基础_偷窃.png`（因为设计早期叫"人类事件卡"），代码硬编码了 `反击卡_`。

**错误3：规则卡+个人目的卡无专用映射**
代码用 `等级_名称` 拼路径（如 `规则卡_普通_禁止饮用可乐`），但：
- 规则卡文件名是编号代码（`规则卡_S-01A.png`、`规则卡_T1-01.png`）
- 个人目的卡文件名是序号（`个人目的卡_01_修仙.png`）
