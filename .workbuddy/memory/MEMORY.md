# 《故事会》项目长期记忆

## 项目工作流程（V1.6起确立）

### 模块化更新模式
- **日常更新**：只改对应子稿/图鉴 + 在`故事会_更新日志.md`追加记录 → 不动总设计稿
- **版本升级**：以旧版总稿为底 + 汇总全部子稿图鉴最新内容 → 从头重写新版总稿
- **权威来源**：子稿和图鉴是唯一权威，总设计稿是版本快照

### 更新日志制度
- 文件：`故事会_更新日志.md`
- 格式：以总稿版本为题头，之后每次子稿/图鉴变更追加一条记录
- 版本升级时，查上一版本题头之后的所有记录 = 新版本需纳入的全部更新

### 双文件制度
- 草稿版（可编辑）+ 底稿版（冻结备份）

### 文件体系（V1.7更新后）
- 总设计稿：V1.7完整版/草稿版/底稿版
