# 《黎明之后》项目长期记忆

## 品牌定位
- **标题**: 黎明之后 | **副标题**: (规则怪谈-推理反击)社交派对游戏
- **术语映射**: 故事会→黎明之后 / 鬼计卡→怪谈卡 / 人事件卡→反击卡
- **核心原则**: "宣言即合法"——玩家互相监督，工具只记录不验证

## 项目工作流程
- **日常更新**: 只改子稿/图鉴 + 更新日志 → 不动总设计稿
- **版本升级**: 以旧版总稿为底 + 汇总子稿图鉴最新内容 → 重写
- **双文件制度**: 草稿版(可编辑)+底稿版(冻结备份)
- **当前版本**: V1.9.3，六个图鉴全部竣工 ✅

## 市民日报三版体系 (2026-07-10~11)
- **共享存储**: `dawn_citizen_daily_v1`(游戏状态) + `dawn_settlement_v1`(结算报告) — 三版日报+仪表盘全互通
- **citizen-daily.html (基础版)**: 6人硬编码、最小化设计、status:'alive'默认、完整鬼魂+回合+结算+终局 ✅
- **citizen-daily-2.html (报纸版)**: 复古报纸美学、鬼魂标记、回合弹窗 ✅
- **citizen-daily-3.html (行政版)**: 行政登记风格、HP/SAN可编辑、完整时间线 ✅
- **鬼魂状态模型**: Citizen对象status字段(alive/ghost/transferred) + isGhost()/isTransferred()/isDead()辅助函数
- **回合推进弹窗**: 🌅黎明扣除(存活市民HP-1) → 🎁生存奖励(F机制:存活≥3回合) → 👻鬼魂理智消耗(SAN-1)
- **结算报告**: {gameStarted, rounds:{dayNum:{dawnHpDeduction,ghostSanityCost,survivalRewardEligible...}}, gameEnded, endReason}
- **游戏终局**: all_dead(全员死亡)自动检测 OR mayor_ended(手动按钮)
- **dashboard.html 仪表盘**: 只读实时面板(统计卡片+市民名单+结算摘要+终局信息+快速启动链接)，已移除手动回合控制
- **身份登入系统** (2026-07-11): 三种身份(市长👑金/记者📰青/警长🛡️蓝) → 各自日报Tab嵌入不同版本(V1/V2/V3)。localStorage `dawn_dashboard_identity`持久化，首次访问弹出选择弹窗，顶部徽章随时可切换。暗色背景修复(--bg-surface替代--bg-base)
