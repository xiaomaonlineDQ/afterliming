# 《故事会》项目长期记忆

## 项目工作流程（V1.6起确立）

### 模块化更新模式
- **日常更新**：只改对应子稿/图鉴 + 在`故事会_更新日志.md`追加记录 → 不动总设计稿
- **版本升级**：以旧版总稿为底 + 汇总全部子稿图鉴最新内容 → 从头重写新版总稿
- **权威来源**：子稿和图鉴是唯一权威，总设计稿是版本快照

### 更新日志制度
- 文件：`故事会_更新日志.md`
- 格式：以总稿版本为题头，之后每次子稿/图鉴变更追加一条记录
- 版本升级时，查上一版本题头之后的所有记录 = 新版本需纳入的全部更新

### 双文件制度
- 草稿版（可编辑）+ 底稿版（冻结备份）

## V1.7.1核心变更（人事件卡系统四等级重构）

### 人事件卡体系
- 四等级：基础36张（12种×3）/觉醒16张（8种×2）/极致6张（6种×1）/真理4张（4种×1）=62张
- 18张已设计完整文本：5基础（分担/慰藉/回响/偷窃/激活）+3觉醒（宿命回响/生死之间/我真是受够你了/自私又有什么错）+4极致（绝境中的一线希望/为有牺牲多壮志/我一定要活下去/末日特别二人组αβ）+2真理（人类群星闪耀时/你们才是挑战者）+4极致占位（敢叫日月换新天等）
- 44张待设计

### 6条获取机制
A初始：第0天基础选取1张→洗切→抽两轮=开局3张（1基础+2未知）
B效果：人物技能或其他事件卡获取
C不屈：人类死亡/化鬼时，剩余全员各抽1张
D智慧：宣言并成功抹除规则达2/4/6次时各抽1张
E奖赏：质询鬼成功，抽1张事件卡或物资卡
F存活：存活到3/6/9/12回合时，该回合黎明抽1张

### 事件卡物理区域
- 未激活区：角色卡左侧平行，不堆叠，盖放
- 已激活区：角色卡右侧平行，不堆叠，公开
- 持续适用区：角色卡顶部垂直，公开持续效果
- 弃牌区：游戏中心，使用后的去处

### 完整流程
获取→置于未激活区→等待激活时机/筹备→成功激活→等待发动条件和时机+满足cost→宣言发动→适用效果→按结算处理结果去往合适位置

## V1.7.1追加更新（鬼事件卡等级体系重构）

### 鬼事件卡体系
- 四等级：流言16张（16种×1）/异常10张（10种×1）/怪诞6张（6种×1）/灾厄4张（4种×1）=36张
- 8张已设计完整文本：1流言（做鬼脸）+4异常（团结的假象/灵异干扰Ⅰ/Ⅱ/Ⅲ）+1怪诞（规则更迭）+2灾厄（夺舍/希望尽头的绝望（占位））
- 28张待设计

### 核心机制
- 所有鬼计卡均为已获得，所有鬼共享牌池
- 开局全部36张处于未激活状态，鬼满足激活条件即可激活
- 已激活鬼计进入全局共享池，任何鬼都可以发动
- 激活和发动手续全部类同人事件卡
- 没有限制区域，但需物理上和视觉上显著轻易区分已激活和未激活
- 数值类鬼计堆叠到目标角色下，其余使用后进入弃牌堆
