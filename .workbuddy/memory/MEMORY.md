# 《故事会》项目长期记忆

## 项目工作流程（V1.6起确立）

### 模块化更新模式
- **日常更新**：只改对应子稿/图鉴 + 在`故事会_更新日志.md`追加记录 → 不动总设计稿
- **版本升级**：以旧版总稿为底 + 汇总全部子稿图鉴最新内容 → 从头重写新版总稿
- **权威来源**：子稿和图鉴是唯一权威，总设计稿是版本快照

### 更新日志制度
- 文件：`故事会_更新日志.md`
- 格式：以总稿版本为题头，之后每次子稿/图鉴变更追加一条记录
- 版本升级时，查上一版本题头之后的所有记录 = 新版本需纳入的全部更新

### 双文件制度
- 草稿版（可编辑）+ 底稿版（冻结备份）

### 文件体系
- 总设计稿：V1.6完整版/草稿版/底稿版
- 10个机制子稿（回合流程、双维属性、交易、宣言质询、堆叠面板、物资卡、鬼身份卡、AI市长、个人目的卡[可能搁置]、祝福遗物卡[可能搁置]）
- 4个图鉴（角色卡、人事件卡、鬼事件卡、规则卡）
- 更新日志
- 项目状态总览
