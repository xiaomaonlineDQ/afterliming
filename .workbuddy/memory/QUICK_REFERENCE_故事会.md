## 核心机制（必须记住）

### 1. 隐藏规则系统
- 鬼有2-4条隐藏规则，人类不知道
- 人类通过"行动→掉理智→反向推理"来推测规则
- 掉理智是唯一的反馈机制

### 2. 事件卡系统（40张鬼 + 24张人）
- **鬼的事件卡**（公开剧本）：40张
  - 基础卡：做鬼脸、窥视之眼
  - 常见卡：灵异干扰、团结的假象（还缺9张）
  - 稀有卡：恐怖剧场、镜像世界、规则更迭（还缺15张）
  - 传说卡：终局谈判、希望尽头的绝望（还缺4张）
- **人的事件卡**（幸存者日志）：24张
  - 传说卡：最后的牺牲、绝境中的一线希望、生死之间（还缺21张）

### 3. 双条件触发体系
- 大多数事件卡需要先满足"激活条件"，再满足"发动条件"
- 只有极少数基础卡允许"即获即发"

### 4. 堆叠式角色面板
- 底部插物资卡（生存资源）
- 顶部插事件卡（命运降临）
- 左侧插鬼的伤害（红色标签）
- 右侧插人的增益（绿色标签）

## 已解决问题（5个）✅

1. **规则更迭**：人类只知道"新进来一个规则"，但不知道具体是什么，也不知道是不是新换的。
2. **绝境中的一线希望**：左右邻座限制是刻意设计的"等待感"+ 绝境氛围。
3. **沉寂的上班族**："前2个完整回合"=全局2轮（1号+2号玩家回合），但目前还没确定用两轮还是整体游戏就一轮。
4. **灵异研究者**：调查期间鬼可以对研究者发动事件卡，只要符合发动时机。
5. **希望尽头的绝望**：接受早期人类多时加大量规则，希望加更多公开规则。

## 设计哲学（必须理解）

### 1. 规则卡"不知道规则"的恐怖体验
- 不是偷懒，是主动设计
- 玩家从"被规则惩罚者"变成"主动解谜者"

### 2. 事件卡的功能定位
- **不是线索来源**，而是**行动驱动力**
- 逼迫玩家行动 → 行动可能触犯规则 → 掉理智 → 推理线索

### 3. 叙事环节的"半真半假"机制
- 鬼不能在故事中对自己规则撒谎（必须提到真实禁忌）
- 但可以添加大量无关细节来误导
- 例：真实规则是"不能提到面包"，鬼讲故事提到面包，但添加父亲、生气、打人等无关细节

### 4. 堆叠面板的物理实体化价值
- 纸笔记录看不到"厚度"
- APP数字界面无法提供"插入动作"的仪式感
- 物理卡牌堆叠本身就是叙事语言
