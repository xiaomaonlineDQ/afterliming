# 图片文件夹说明

将美术素材放入对应文件夹后，网站会自动从占位框切换为真实图片。

## 目录结构

```
docs/images/
├── logo.png                          # 游戏Logo（正方形，建议150×150以上）
├── cards/                            # 卡牌图鉴用图
│   ├── 反击卡_基础_抗争.png          # 命名格式：{类型}_{等级}_{卡名}.png
│   ├── 反击卡_觉醒_绝境逆转.png
│   ├── 怪谈卡_流言_做鬼脸.png
│   ├── 规则卡_T1_不可说死字.png
│   └── ...
└── characters/                       # 角色头像/立绘
    ├── 乐天派幸存者.png              # 命名格式：{角色名}.png（与图鉴一致）
    ├── 天生幸运儿.png
    └── ...
```

## 命名规则

- **卡牌**：`{卡牌类型}_{等级}_{卡名}.png`
  - 类型：反击卡 / 怪谈卡 / 规则卡 / 物资卡
  - 等级：基础/觉醒/极致/真理（反击卡）、流言/异常/怪诞/灾厄（怪谈卡）、T1/T2/T3（规则卡）
  - 特殊字符自动转下划线

- **角色**：`{角色名}.png`
  - 角色名与角色卡图鉴中的名称完全一致
  - 建议尺寸：400×600（立绘）或 200×200（头像）

## 使用方式

1. 将美术输出的PNG按上述命名格式放入对应文件夹
2. 网站自动检测：图片存在 → 显示真实卡面；不存在 → 显示占位虚线框
3. 不需要修改任何代码
