《黎明之后》是一款规则怪谈×推理反击的社交派对桌游。

核心设定：

  • 12名幸存者被困在A市，城市被诡异的隐形规则支配。
  • 其中1人是煞鬼——他持有隐藏规则卡，这些规则影响所有玩家的行为。
  • 人类的胜利条件：在12回合内推理并抹除所有隐藏规则，或用反击卡击杀鬼。
  • 鬼的胜利条件：在12回合结束时至少1条隐藏规则未被抹除，或所有人类死亡/化鬼。

双维属性：

  • 健康值：初始7，每日黎明扣除1。归零=死亡。
  • 理智值：初始7，受怪谈和规则影响。归零=化鬼。
  • 死亡转化为恶鬼（新鬼继承旧鬼规则继续对抗人类）；化鬼直接成为恶鬼。

五类卡牌：

  • 怪谈卡（鬼用）· 反击卡（人用）· 规则卡（核心）· 角色卡（身份）· 物资卡（生存）

第0天是游戏开始前的准备阶段，共11步：

  1. 角色分配：每位人类玩家从洗切的角色卡中随机抽取1张。
  2. 鬼身份确定：秘密抽取鬼身份卡，确定煞鬼。
  3. 地图设置：铺设A市12地点地图板，每个玩家选择初始地点。
  4. AI市长初始化：输入玩家编号、角色名、初始地点。
  5. 开局随机判定：AI市长随机分配初始物资等。
  6. 煞鬼选择规则：鬼从规则牌库中抽取并秘密选择隐藏规则。
  7. AI市长生成煞鬼故事：基于鬼的初始地点和隐藏规则生成N段故事。
  8. 基础反击卡分配：每人从基础反击卡中选取1张，洗切后抽2张（开局共3张）。
  9. 个人目的卡分配：每人抽取1张秘密个人目的卡。
  10. 初始物资分配：按角色和地点获得初始物资。
  11. 回合指示卡初始化：每人获得对应角色属性的四维度分隔符。

每个回合（Day 1-12）包含以下阶段：

  1. 市长的叙事：AI市长讲述一段煞鬼故事（基于隐藏规则生成的叙事）。
  2. 物资补给：官方补给或地图探索，二选一。
  3. 交易阶段：玩家之间自愿交易物资卡。
  4. 宣言阶段：人类玩家可以宣言猜测隐藏规则。
  5. 质询阶段：人类可以质询鬼的行为是否触犯规则。
  6. 怪谈激活：鬼检查是否有怪谈卡满足激活条件。
  7. 反击卡发动：满足发动条件的反击卡可以在合适时机发动。
  8. 黎明阶段：AI市长结算本回合数值变更、判定生死。

详细完整流程请参阅流程图。

宣言：人类玩家猜测隐藏规则的具体内容。

  • 每个回合每人有 ?+1 次宣言机会（?为基础次数，+1为奖励）。
  • 宣言正确 → 规则被抹除，获得反击卡抽取机会（智慧机制）。
  • 宣言错误 → 理智 -1。

质询：人类玩家质疑鬼的行为是否触犯了某条公开规则。

  • 每位玩家整局游戏只有 2次 质询机会，不限时机。
  • 质询成功 → 鬼受到惩罚，质询者抽1张反击卡或物资卡。
  • 质询失败 → 质询者理智 -2。

公开规则栏：被宣言抹除的规则会公开到规则栏板上，所有人可见（四分区物理板）。

AI市长是游戏的必需组成部分（真人市长也使用AI辅助）。

6步工作流程：

  1. 确认玩家编号和角色名
  2. 开局随机判定（随机分配初始物资等）
  3. 确认初始选择 + 生成煞鬼初始故事（基于隐藏规则生成N段故事）
  4. 每回合：记录宣言 + 讲述故事段 + 规则变更确认
  5. 回合结束：数值结算判定
  6. 终局：生成全玩家生存日记

核心原则：

  • 市长是冷静的末世书记官——不是DM，不闲聊，零冗余。
  • "宣言即合法"——玩家互相监督卡牌合法性，市长只记录。
  • 不主动透露任何未公开宣言的信息。

人类胜利：

  • 在12回合内推理并抹除全部隐藏规则；或
  • 用反击卡或其他手段击杀全部鬼。

鬼胜利：

  • 12回合结束时仍有至少1条隐藏规则未被抹除；或
  • 所有人类玩家死亡或化鬼。

终局：无论谁赢，AI市长都会生成一份全玩家生存日记，记录这场游戏中发生的故事。
