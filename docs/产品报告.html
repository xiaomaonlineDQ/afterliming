Design Philosophy

设计哲学

规则为骨 —— 让"不知道规则"成为玩法

01
不知道规则 → 推理规则

传统桌游的规则是玩家阅读后遵守的。本游戏的规则是玩家观察后推理的。你不知道边界在哪，但你知道自己越界了——因为理智值在下降。这种"不确定中的确定惩罚"正是灵异怪谈类作品的核心心理机制。我们把它做成了一款桌游。

02
规则约束所有人，包括鬼

鬼制定了隐藏规则，但这些规则同样约束鬼自己。信息不对称是游戏的核心乐趣，但规则面前人人平等——这是博弈空间的保证。鬼也可能被其他鬼利用规则攻击。

03
物理实体承载情感

堆叠式角色面板让玩家"看到"自己的生存历程；公开规则栏让所有人随时感知规则的压迫；硬币掷出的正反面不只是判定，是命运。每一个物理组件都是为了制造某种情感反馈而设计的。

Core Gameplay

核心玩法：宣言推理

让"不知道规则"成为玩法

① 观察 违反规则的玩家理智下降，所有人观察到"有人受罚了"
② 猜测 人类阵营结合AI市长的海龟汤式故事和游戏中的异常现象，推理规则
③ 宣言 大声宣言："我推理第X条规则——[规则内容]"
④ 质询 鬼可以发起质询，质疑推理过程或证据链
⑤ 判定 鬼拿出对应规则卡验证。正确→规则抹除；错误→宣言者扣1理智
设计亮点
▸ 每人每回合限1次宣言
▸ 宣言次数达2/4/6次抽事件卡
▸ 宣言成功 → 规则永久抹除
▸ 宣言失败 → 扣1理智
▸ 鬼可发起质询打断
▸ 宣言即合法：玩家互相监督
   市长不做法官
Survival System

双维属性：两条独立的死亡路径

饿死 vs 疯掉 —— 资源管理与心理博弈的交叉压力

健康值（体力）

起始：6点

消耗途径

· 每日黎明自动扣除（递增：1→2→3...）
· 移动消耗（越远扣越多）
· 事件卡效果

恢复途径

· 物资卡（食物类）
· 反击卡效果
· 交易获取物资

⚠ 健康值降至0 → 饿死

理智值（精神）

起始：6点

消耗途径

· 违反鬼的隐藏规则 → 扣理智
· T1规则扣3点 / T2扣2点 / T3扣1点
· 怪谈卡效果

恢复途径

· 反击卡效果（极少）
· 特殊角色技能

⚠ 理智值降至0 → 化鬼

化鬼后加入鬼阵营，人类全员抽反击卡

Paradigm Shift

AI市长：桌游主持的范式转移

零门槛开桌 + 海龟汤式恐怖叙事

传统桌游的痛点

✕ 需要DM/主持人：缺人就开不了桌
✕ DM水平参差：新手DM严重影响体验
✕ 规则复杂：学习成本高，劝退新玩家
✕ 叙事重复：老玩家反复玩缺乏新鲜感

AI市长的解决方案

✓ 零门槛：打开手机/电脑即可开桌
✓ 一致性：严格按照预设指令执行，不偏袒
✓ 海龟汤叙事：每局生成独一无二的恐怖故事
✓ 自动化：记录宣言、结算数值、生成终局日记

AI市长 6步工作流程

0. 确认玩家 → 1. 开局判定 → 2. 生成故事 → 3. 每日黎明 → 4. 记录回合 → 5. 结算数值 → 6. 终局日记

海龟汤难度叙事 → "不讲因果链，只讲日常碎片" —— 故事让玩家知道"规则长什么样"，但不告诉"规则在哪里"
